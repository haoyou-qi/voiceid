# VoiceID 電腦運算：讓手機用你家電腦辨識字幕

手機（或眼鏡）負責收音、環境偵測、聲紋辨識和顯示字幕。字幕辨識交給你的電腦跑比較大、比較準的模型。
電腦沒開時，網站會自動改回手機運算，字幕不會中斷。

## 實測效果（吵雜環境測試集：15 句中英文 × 音樂／人群／車聲／咖啡廳 × 3 種吵雜程度）

| 情況 | 手機運算（現在） | 電腦運算 |
|---|---|---|
| 安靜 | 6.7% | 4.1% |
| 人群吵雜 | 41.6% | 18.5% |
| 背景音樂 | 46.9% | 22.8%（有音樂時自動 AI 降噪） |
| 咖啡廳（人聲＋音樂） | 41.2% | 19.8% |
| 車聲 | 9.6% | 4.2% |
| **吵雜環境平均** | **34.9%** | **約 16%（錯字少了一半以上）** |

數字是「錯字率」，越低越好。電腦運算還會自動加上標點，英文會有大小寫。
測試集的雜音是用其他人的錄音和合成的音樂、車聲混出來的，實際的餐廳、街道效果可能不同，請實際測試。

**AI 降噪的實測結論**：只有「有音樂、沒有人群」時開降噪才有幫助（37.6% → 22.8%）。
人群吵雜時降噪反而會變差（18.5% → 22.1%），因為降噪模型會把要聽的人聲也一起削掉。
所以電腦會依照手機偵測到的環境自動決定要不要降噪，不用手動切換。
要從人群中只留下某個人的聲音，需要「目標說話者擷取」，屬於下一階段。

## 第一次設定（約 15 分鐘，只要做一次）

### 1. 安裝電腦運算服務
雙擊 `server\setup_pc.bat`。它會自動找到你的 Python（Anaconda 也可以）、安裝 onnxruntime、下載模型（約 240MB）。

### 2. 啟動服務
雙擊 `server\start_server.bat`，視窗會顯示：

```
VoiceID 電腦運算服務已啟動：http://localhost:8765
通行金鑰：xxxxxxxxxxxx
```

**通行金鑰**是手機連進來用的密碼，存在 `server\config.json`。想換一組金鑰，就刪掉這個檔再重新啟動。

### 3. 讓外面的手機連得到（Tailscale Funnel，免費、網址固定）
1. 到 https://tailscale.com/download/windows 下載並安裝 Tailscale，用 Google 帳號登入
2. 在 `server\tailscale_funnel.bat` 上按右鍵 →「以系統管理員身分執行」
3. 第一次執行時會出現一個網址，用瀏覽器打開並按允許，開啟 Funnel 功能，再執行一次這個 bat
4. 畫面會顯示你的固定網址，例如 `https://desktop-3a1ncbr.tail1234.ts.net`。這個網址以後都不會變

> 為什麼不用 Cloudflare：Cloudflare 的免費快速通道每次重開都會換網址，朋友就得一直改設定。Tailscale 的網址是固定的。

### 3-1. 改成私人模式（建議：只有你和朋友連得到）
公開網址（Funnel）任何人都連得到入口，網路上的掃描程式也會來試探。私人模式只讓「登入你的 Tailscale」或「接受你分享」的人連線，網址不變。
1. 在 `tailscale_private.bat` 上按右鍵，選「以系統管理員身分執行」：會關閉公開網址，改成私人網址
2. **你的手機**：安裝 Tailscale App，用同一個 Google 帳號登入，打開連線
3. **分享給朋友**：到 https://login.tailscale.com/admin/machines → 你的電腦（desktop-3a1ncbr）右邊的「⋯」→「Share」→「Copy invite link」，把連結傳給朋友
4. **朋友**：安裝 Tailscale App，用自己的帳號登入，打開你給的邀請連結並接受，之後使用 VoiceID 時要讓 Tailscale 保持連線
5. 朋友只看得到你分享的這台電腦，看不到你其他的裝置；你也可以隨時在同一個頁面取消分享（Revoke）

### 4. 開機自動啟動（建議）
雙擊 `server\autostart_on.bat`。它也會問你要不要讓電腦插電時不睡眠，朋友才隨時連得到。

### 5. 手機設定
打開 VoiceID 網站 →「即時字幕」→「運算方式」：
- 「電腦網址」填第 3 步的 `https://….ts.net`
- 「通行金鑰」填第 2 步的金鑰
- 按「連線」。出現「已連上電腦」，右邊的標籤也會變成綠色的「已連上電腦」

**給朋友最簡單的方法**：直接傳下面這種連結，朋友點開就會自動填好（填好後網址列會自動清掉金鑰）：

```
https://haoyou-qi.github.io/voiceid/?pc=你的ts.net網址&k=通行金鑰
```

## 運算方式三個選項

- **自動**（預設）：電腦有開就用電腦，沒開或斷線就用手機。斷線後每 10 秒會自動重連
- **只用電腦**：電腦沒開時字幕會暫停（手機最省電）
- **只用手機**：跟以前一樣，完全不用網路

## 要注意的事

- **網路流量**：每小時約 100MB（聲音以 16kHz 傳輸），建議朋友的網路方案不要太小
- **延遲**：串流字幕跟手機一樣即時；每句話說完後約 0.3–1 秒，會換成較準、有標點的版本
- **隱私**：聲音只在電腦記憶體中處理，不會存檔；Tailscale 不會解開加密內容。仍建議先跟朋友說明聲音會經過你的電腦
- **安全**：只開放這個語音服務，電腦上的其他東西都碰不到。沒有通行金鑰的人連不進來。金鑰外流時，刪掉 `config.json` 再重新啟動就能換一組新的
  - 別人直接打開網址只會看到「Not Found」，看不出這是什麼服務
  - 同一個來源 10 分鐘內輸錯金鑰 5 次，會被封鎖 30 分鐘；錯誤次數越多，每次回應也越慢（最多 10 秒）。用正確金鑰連線不受影響
  - 有人用錯誤金鑰嘗試連線時，服務視窗會顯示 ⚠ 提醒，看到很多次就建議換一組金鑰
  - 連上後 10 秒內沒送出金鑰就會斷線
- **同時連線**：最多 4 支手機同時使用
- **聲紋辨識**：還是在手機上做，聲紋檔不會傳到電腦
- **用電腦運算時，手機會自動收原始聲音**（網站上的「降噪」開關只在手機運算時有效），電腦的模型用原始聲音最準
- 如果 Tailscale 更新後，外面的手機突然連不到，可以到 Tailscale 官方查看是否有已知問題，或重新執行 `tailscale_funnel.bat`
